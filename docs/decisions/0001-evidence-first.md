# ADR 0001 · 以历史改革证据作为首版核心

2026-11-09，采用。

这份记录说明首版为什么以历史改革证据为核心，以及放弃了哪些方案。

团队无法开展线下试点，但需要用过去改革及其结果论证方案，所以首版把历史改革证据作为核心：实现面板、简单 DiD、诊断和单项改革约束比较，统计实现调用 statsmodels。采用 src 布局、默认离线运行；原创代码、文档和合成示例用 MIT。

备选方案是纯文档论证，但数值无法核验；完整知识图谱、多 Agent 和前后端平台目前缺少校准材料与工程投入，后续独立接入。多期改革、复杂混杂、课程交互和四年反馈需要新的研究设计，不在首版范围。

识别方式或效应传递方式变化时，新增决策记录并补测试。
