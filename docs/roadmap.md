# 路线图

## 当前目标

把一个真实专业的需求线索转成具体培养动作，再用可核验历史证据及明确情景论证结果。先完成窄范围研究，再扩展赛题的方向、招生、风险和交付。目标与官方要求统一见 [项目说明](project.md)，当前偏移见 [状态](status.md)。

## M1 · 真实输入与动作

取得一个学校、专业、版本的公开培养方案，记录课程、学分学时、先修、类别和来源。先支持可核对的课程切片，完整方案和资源逐步补齐。把一个实践教学调整写成具体课程动作，分别记录公开事实、决策假设及教师待审项。

验收需要真实输入、保持原方案、至少一个具体候选、前后课时学分、约束检查和原文定位。未知条件列出材料缺项。增加实践投入只作为过程代理。

## M2 · 历史改革与可信效果

选择与候选动作相符的历史改革或实证研究，记录处理措施、人群、时间窗、结果指标和识别条件。优先复核可获得的数据与估计；仅有论文报告值时，标记复核层级并审查迁移条件。纳入无效和失败案例。

验收需要一条可核验的措施效果证据、原始来源、效应范围、识别与外推限制。按证据支持的指标给出条件性结果，学生就业效果缺数据时保持未识别。后续案例充足后留出学校或整项改革做外部回测。

## M3 · 固定判据下的候选迭代

生成有限候选，按已冻结约束和评价标准计算，记录失败原因并修订候选。比较原方案、候选、零效应、负效应和假设改变后的结果，给出优势消失的条件。评价依据与候选提出过程分开，避免用自定规则证明自身方案有效。

验收需要可重复的生成、评价、反思及修订记录，至少一项与动作直接关联的可量化结果或清楚的未识别状态。需求预测分数只作线索；培养收益由 M2 的证据支持。

## M4 · 补齐赛题四任务

扩展到完整培养方案，补技能结构、培养方向和规模匹配三维量化。形成具体课程调整、方向分流时点与门槛/容量规则，以及带培养时滞的就业反馈招生机制。至少三类风险与实际动作绑定，列影响、责任、时间和预警。

验收按官方任务分别核对输入、动作和结果，无法估计的项保留具体补件需求，局部成果不提升为全专业结论。

## M5 · 最小演示与交付

核心研究结果冻结后，再整理报告 PDF、数据支撑、五分钟内视频和答辩 PPT。用轻量本地界面或正常入口呈现实际决策过程，统一版本、哈希、数字与解释范围。

验收包括新环境复现、材料一致性、视频时长、显示和打印检查、数据许可与公开范围。已有草稿仅按新结果更新。

## 调度规则

当前优先 M1 与 M2。数据库、更多年份回测、界面、问答和排版只在这些任务需要时扩展。缺少某项校内材料时继续推进公开方案、可验证历史案例和条件性分析，同时记录剩余依赖。任务完成按可审查结果判断，代码与研究分别验收。

## 本轮实施顺序

1. 固化已验收的 F1–F5，推送特性分支与 PR，保留人类合并权限。
2. 提取 147 学分与模块要求，检查包含/不包含调出选修课、进阶学分有无富余的三种路径。修复边界数值错误，补模块违规反例。
3. 接入原单位的历史效应、迁移范围与偏差假设，输出三情景、零效应与负效应对照，报告适用性缺项。
4. 实现方向容量与分流规则、带培养时滞的招生反馈，以及动作绑定的风险矩阵。真实观测与合成运行分别标记。
5. 由统一研究结果生成材料审阅版，检查报告/PPT/视频/数据支撑是否齐全、数字是否一致。正式放行必须补齐任务证据和许可，最终压缩包保留版本及 SHA-256。
