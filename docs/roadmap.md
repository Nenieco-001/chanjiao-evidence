# 路线图

这份文档列出从基础工程到完整赛题的里程碑。M1–M4 尚未开展，进度通过 Issue、PR 与 `CHANGELOG.md` 更新。

## M0 · 基础工程

可安装包、CLI、合成改革与零效应、诊断、单项方案约束、哈希、测试和 CI。以正常入口和独立手算验收。

## M1 · 真实材料

搜集至少两个可核验的真实改革卡片，包含前后培养方案、时间、连续指标、对照和同期变化。收录无效或资料不足案例，核对许可、清洗与口径。取得真实面板后，才能开展真实改革效应估计。

## M2 · 估计与历史回测

按数据选择 DiD、工具变量等设计；分期改革评估成熟的多期实现；补充对照、趋势与未观测混杂分析。留出学校或整个改革，报告误差、覆盖和迁移失败。先固定分析规则再运行。

## M3 · 动作与优化

整合岗位—能力—课程—改革证据图谱。补先修、师资、容量、方向分流和被替代课程损失，拿到交互证据后接入联合优化器。比较原方案、纯供需匹配、平均效应与保守效应方案。

## M4 · 完整赛题

数据允许时接入真实行为校准的学生模型，补四年情景、方向分流、就业反馈招生和实施风险。每项有独立数据与验收。
