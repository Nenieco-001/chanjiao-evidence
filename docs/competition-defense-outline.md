# 产教智对：答辩 PPT 与演示视频大纲

本稿规划 **12 页答辩 PPT** 和 **不超过 5 分钟的六段视频**，尚未制作实际幻灯片或视频。
报告主文使用[参赛报告草稿](competition-report-draft.md)，数字依据
[已验收分析报告](competition-analysis.md)，运行与分母定义见
[工作台 README](../analysis/competition/README.md)。需求侧已验收不等于完整参赛材料已通过验收。
统一口头结论：已有需求侧描述与回顾性回测；真实供给与学生结果缺失，方案和效果仍需补证据。

## 一、逐页答辩大纲

### 第 1 页｜问题：怎样把需求线索变成可执行的专业调整？

- 要点：计算机科学与技术 × 北京/上海 × 电子设备制造、软件和信息技术服务；学校待定。
  四任务为差距、方案、验证、风险，分别说明当前进度。
- 图表：四任务进度图；需求侧写“已有结果”，供给、方案、培养效果写“待补”。
- 口头结论：“我们已完成限定样本的需求分析，接下来用真实学校材料决定哪些调整值得做。”
- **证据 / 假设 / 待补**：目标与范围来自报告第一节 / 岗位族是专业需求代理 / 学校与届别待补。

### 第 2 页｜数据口径：每个分母都能回查

- 要点：historical 招聘、分年字段语义、年度内近似去重；上市公司行业标签不等于逐岗位行业。
  2016/2023 全年，2026 截止 03-10；回测用 2024/2025，匿名来源变化。
- 图表：字段映射与过滤流程图；附数据来源、版本、窗口、许可状态栏。
  展示聚合字段，原文定位与受限记录留本机。
- 口头结论：“这些是明确筛选口径内的岗位发布记录，不能直接当市场规模或应届生需求。”
- **证据 / 假设 / 待补**：报告第一节与工作台固定口径 / 既定岗位筛选规则 / 字典、平台身份、许可待补。

### 第 3 页｜三个年份画像：分别描述，不画总量趋势

- 要点：去重样本为 **12,678 / 4,035 / 286**；每年标城市、行业、窗口和技能分母。
  2023 Python 高提及与平台构成同时展示，解释为需人工复核的文本线索。
- 图表：`verified-final-01/skills-2016.svg`、`skills-2023.svg`、`skills-2026.svg` 三个独立面板，
  统一比例尺；图下标“技能词面提及，非必备要求”。报价另用小卡，按报告原数标“非毕业生起薪”。
  文件均位于本机 `artifacts/competition-analysis/`；本批没有重绘或重新渲染。
- 口头结论：“画像说明这批记录提到了什么，跨年覆盖不同，不能解释为全国需求变化。”
- **证据 / 假设 / 待补**：报告三年度数值及既有 SVG / 月薪单位按字段解释 / 人工技能标签与可公开图件待补。

### 第 4 页｜三维差距：供给没有到手，缺口不能先写结论

- 要点：技能结构、培养方向、规模匹配各列已有需求与缺失供给。
  缺真实培养方案、大纲、学分、学生能力、招生与就业结果。
- 图表：三维差距清单，单元写“已有需求 / 供给待补 / 当前不可判断”；
  放 schema 字段示意，固定标识 `synthetic / 示例占位`，学校和来源为 null。
  不使用伪造学校课表、学分图或学生就业图。
- 口头结论：“示例接口只验证数据如何接入，当前没有真实学校缺课量。”
- **证据 / 假设 / 待补**：报告第一节供给接口与现有 schema / 词面覆盖仅是内容线索 / 真实方案与教师核验待补。

### 第 5 页｜课程动作：每项增减都说明目标由谁承接

- 要点：展示一张空白动作单：动作类型、原文位置、前后学时/学分、先修、学期、目标承接、成本与审批。
  证据、教学假设、待决策分别填；不把高频技能占比换成学时。
- 图表：报告第二节课程模板，数值栏统一“待补”；“原方案 → 候选 → 资源/目标审核”流程。
- 口头结论：“课程建议必须同时回答为何改、删掉什么、谁来教、怎样考核；目前尚无真实动作获核定。”
- **证据 / 假设 / 待补**：已有需求分组 / 动作到能力的机制未校准 / 大纲、目标承接与资源清单待补。

### 第 6 页｜方向与招生：由资源和反馈决定，不按词频分人数

- 要点：方向模板含意愿、先修、容量、候补、补修与转向。
  招生反馈需届别、毕业供给、就业分母、吸纳人数与时滞；缺输入就无法判断。
- 图表：方向申请与容量审核流程；“已知届别反馈 → 口径核验 → 多届资源检查 → 审议”闭环。
  阈值、上限、人数均标“待决策”，不展示未经验证的扩缩招曲线。
- 口头结论：“我们给出可填写、可审核的机制，当前不建议任何扩缩招比例。”
- **证据 / 假设 / 待补**：报告第二节方向与招生模板 / 时滞及流动需依据 / 容量、学生意愿和就业反馈待补。

### 第 7 页｜全年回测：简单方法也有无优势结果

- 要点：两折分别只用截止年可用年度；比较最近年度与年度等权均值。
  2024 均值法份额误差较小但 Top-5 与薪资较差，2025 三项误差均未优于最近年度。
  岗位 MAE/TVD、技能 MAE/Top-5、薪资报价误差分开。
- 图表：按报告第一节八条回测摘要中的四条全年结果排两折对照；
  图注列目标分母 **3,272 / 3,560**，比例误差与元/月分轴，不合成单一“准确率”。
- 口头结论：“回测衡量样本结构与报价摘要的误差，不衡量课程改革收益，也没有一种方法全面占优。”
- **证据 / 假设 / 待补**：已验收全年回测 / 非来源与季节匹配的年度对照 / 真正未见评价集待补。

### 第 8 页｜共同支持：可比范围收缩到 597 与 39 条

- 要点：逐层共同值后还要六维完整组合交集；平台同号可比仍待确认。
  2024 为 **597/3,272（18.25%）**，2025 为 **39/3,560（1.10%）**。
  2024 均值法技能 MAE 更差，2025 没有严格优势；保留空组、小样本和跨年重叠。
- 图表：依据报告的样本流画两折收缩图，六层与完整组合分别标名；
  边栏列“2024 平台13仅 1 条 / 2025 电子设备制造业仅 2 条”。
  共同支持误差与全年误差分面展示，标“比较对象不同”。
- 口头结论：“共同支持暴露了可比性边界，尤其 2025 的低误差不能代表全年市场。”
- **证据 / 假设 / 待补**：报告共同支持、失败组与重叠计数 / 匿名平台同源未确认 / 企业隔离、权重与区间待补。

### 第 9 页｜验证框架：冻结方案，再检查同条件差值

- 要点：分清输出正确、需求回测、情景内部一致、真实培养效果。
  后两层目前没有本校结果；2026 已参与探索，不能称独立留出。
  后续同预算比较原方案、贪心、名义与稳健候选，乐观/基准/悲观参数逐项登记依据。
- 图表：证据分层图；开发/冻结/评价流程；参数来源空白清单。
  四年就业率、起薪、技能匹配度统一写“待补，当前不可估计”，不画假收益柱。
- 口头结论：“需求回测已经运行，学校方案验证仍是协议；没有数据就不报告四年培养收益。”
- **证据 / 假设 / 待补**：报告第三节及已读研究设计 / 教学机制和情景尚待校准 / 历史结果与独立评价待补。

### 第 10 页｜失败与反转：什么条件下应保留原方案？

- 要点：无共同支持停止评分；资源或目标底线违规判不可行；
  教学增益不足、负荷与成本抵消、合理权重变化导致反转时保留或重审原方案。
  已观察的回测无优势与尚未测量的教学反转条件分开。
- 图表：失败条件清单与处置流程；反转阈值位置留“待估计”，不用虚构的敏感性曲线。
- 口头结论：“可复核的建议要允许失败；我们保留无优势结果，也明确还没有本校收益反转数值。”
- **证据 / 假设 / 待补**：真实回测失败项 / 教学反转属于待检验条件 / 参数依据与阈值待补。

### 第 11 页｜风险应对：触发后由谁做什么？

- 要点：师资容量、学生适应、数据许可、平台覆盖、代理误用；
  每项给触发、影响、动作、责任角色，具体人名与阈值待填。
- 图表：直接据报告第四节排风险处置卡，不填未经观测的概率或风险评分。
- 口头结论：“资源不够就缩小动作，证据不够就停止判断，公开材料先核实许可。”
- **证据 / 假设 / 待补**：已有覆盖问题和供给缺失 / 风险触发为管理设计 / 校方承诺、实名负责人和许可待补。

### 第 12 页｜交付与下一步：证据补齐后再形成学校建议

- 要点：报告 PDF、可运行支撑脚本/表格、视频、PPT 共用一套结论。
  当前完成需求侧分析与交付物骨架；真实供给、学校方案和培养效果未完成。
  下一步顺序：材料与许可 → 教师核验和候选 → 冻结评价 → 同版本交付。
- 图表：评审五维度与证据页码索引；附件清单，标版本、窗口、分母和已完成/待补。
- 口头结论：“现有贡献是可追溯的需求证据与明确的决策接口，真实调整结论需要学校材料。”
- **证据 / 假设 / 待补**：本稿与报告的同一来源索引 / 暂无新的效果假设 / PDF、PPT、视频制作及最终验收待补。

## 二、五分钟视频：六段脚本

以下分配合计 **300 秒**，是制作预算，尚未录制或实测时长。剪辑后含转场与片尾也须不超过五分钟。
旁白以引号内文字为主，画面标注在整个片段持续显示；不朗读全部指标。

1. **问题｜00:00–00:35，35 秒；对应第 1 页。**
   画面：专业、城市、行业及四任务图。
   旁白：“专业调整要回答三件事：需要什么、学校能教什么、改后凭什么认为更好。
   我们聚焦计算机科学与技术及北京、上海的两类行业。当前完成需求侧分析，
   真实学校供给和学生结果仍待取得，因此本次展示已知证据和后续决策骨架。”
2. **数据｜00:35–01:20，45 秒；对应第 2–3 页。**
   画面：字段映射、去重流程与三个独立年度技能面板，持续显示窗口与分母。
   旁白：“我们按年度核对字段，在目标样本内近似去重，得到 2016、2023、2026 年初
   的 12,678、4,035、286 条记录。2026 只到三月十日，来源覆盖又不同，
   所以不画市场总量趋势。技能是文本提及，薪资是岗位报价，不能当必备能力或毕业生起薪。”
3. **差距｜01:20–02:00，40 秒；对应第 4 页。**
   画面：技能结构、方向、规模三维清单；供给格为“待补”；示例接口标 synthetic。
   旁白：“需求画像可以形成核验线索，却不能单独算学校差距。
   我们还缺培养方案、大纲、学分、考核与招生就业反馈。当前课程文件只是人工接口样例，
   没有真实学校来源。三维差距都保留待核验，不能把未命中技能直接写成缺课或扩招理由。”
4. **方案｜02:00–02:50，50 秒；对应第 5–6 页。**
   画面：课程动作单、方向分流流程、招生反馈流程，所有未取得数值显示“待补”。
   旁白：“课程增减要填清前后学时、目标承接、先修、师资和成本，证据、假设、待决策分栏。
   方向分流还要核对意愿、容量、候补与转向。招生调整需要届别就业反馈、培养时滞和资源核算。
   这些模板让组员补齐后可以审议，目前没有已选出的真实方案或扩缩招比例。”
5. **验证｜02:50–04:10，80 秒；对应第 7–10 页。**
   画面：两折全年对照 → 共同支持收缩 → 四层证据 → 失败条件。
   旁白：“已运行的验证是需求样本回测，比较保持最近年度和年度均值。
   全年 2024 的均值法份额误差较小，但薪资和 Top-5 较差；2025 没有误差优势。
   严格共同支持后，2024 只剩 597 条，覆盖 18.25%；2025 仅 39 条，覆盖 1.10%。
   匿名平台尚未确认同源，跨年企业也未隔离，2026 已参与探索，所以不能称独立留出。
   后续需要冻结学校候选，用相同条件做对照和情景检验。
   资源违规、教学增益不足或独立评价无优势时，要保留原方案。当前不报告四年就业收益或因果结论。”
6. **风险｜04:10–05:00，50 秒；对应第 11–12 页。**
   画面：风险处置卡、待补材料与四件交付物清单；片尾保留证据边界。
   旁白：“师资不足就先核定容量并缩小动作；学生适应困难要有补修和转向；
   许可不明就先确认公开范围。平台偏差和代理指标误用也由专人复核。
   下一步取得学校材料和许可，再定候选、冻结评价，最后让报告、脚本、视频和答辩使用同一版本。
   我们现在交付需求证据与设计骨架，学校调整和真实效果仍待补证据。”

- **证据 / 假设 / 待补**：旁白数字逐条对应报告 / 分段时长是剪辑安排 / 实际素材许可、录音、转场和成片计时待完成。

## 三、评审五维度对应证据

- **差距分析准确性｜第 2–4、8 页；视频“数据/差距/验证”。**
  证据：分年规则、三年度分母、技能提及、支持覆盖和三维待核验清单。
  对应报告第一节；真实供给差距尚未量化，不宣称完整准确率。
- **方案可操作性｜第 5–6 页；视频“方案”。**
  证据：课程动作、方向分流、招生反馈三类模板及资源/目标/审批字段。
  对应报告第二节；待学校填写与教师核定，不能称已获批准的可执行方案。
- **验证说服力｜第 7–10 页；视频“验证”。**
  证据：全年与共同支持回顾性误差、无优势、空组、重叠风险，及冻结后同条件评价协议。
  对应报告第一、三节；真实改革效果及四年预测尚无证据。
- **风险评估与应对｜第 10–11 页；视频“风险”。**
  证据：失败/反转条件和逐项风险处置卡，含影响、动作与责任角色。
  对应报告第三、四节；具体负责人、容量承诺和许可答复待补。
- **材料规范与现场表现｜第 2、12 页及全片。**
  证据：共同来源索引、historical/synthetic 标识、窗口/分母/单位、可复核运行入口与版本清单。
  对应报告开头及第四节；最终 PDF/PPT/视频尚未制作，外部链接与公开许可未重新核验。

- **证据 / 假设 / 待补**：五维度来自赛题说明，页码对应本稿 / 无评分权重或获奖预测 / 交付前统一冻结数字、核对图注与许可并彩排。
